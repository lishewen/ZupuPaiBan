# 族谱排版软件实现方案

## 技术栈

- **框架**: .NET 8 + WPF
- **数据库**: SQLite (via Microsoft.EntityFrameworkCore.Sqlite)
- **MVVM 框架**: CommunityToolkit.Mvvm
- **打印**: WPF 内置打印 (System.Printing + PrintDialog)
- **图片处理**: 内置 BitmapImage

## 核心数据模型

### FamilyMember
- Id (int, PK)
- Name (string) - 姓名
- Gender (enum: Male/Female)
- BirthDate (string) - 出生年月
- DeathDate (string?) - 卒年月（可为空表示在世）
- SpouseName (string?) - 配偶姓名
- Biography (string?) - 生平事迹
- PhotoPath (string?) - 照片路径
- FatherId (int?) - 父亲 ID（外键，自引用）
- Generation (int) - 第几代（辈分）
- BirthOrder (int) - 同辈中的出生排序

### LayoutSettings
- PageSize (枚举: A3/A4/A2)
- Orientation (枚举: 纵向/横向)
- NodeWidth / NodeHeight - 成员节点尺寸
- HorizontalSpacing / VerticalSpacing - 节点间距
- FontSize - 字体大小
- ShowPhoto (bool) - 是否显示照片
- ShowSpouse (bool) - 是否显示配偶
- ShowBiography (bool) - 是否显示生平
- Title (string) - 族谱标题（如"XX氏族谱"）
- TitleFontSize - 标题字号

## 功能模块

### 1. 成员管理模块 (MainWindow + MemberEditDialog)
- 左侧面板：树形/列表显示所有成员，支持展开折叠
- 右键菜单：添加成员、添加子成员、编辑、删除
- 编辑对话框：表单输入所有字段，含照片选择预览
- 支持拖拽调整同辈排序

### 2. 树形布局算法 (TreeLayoutService)
- 从数据库加载所有成员，构建内存中的树结构
- 采用分层布局算法：
  - 按辈分(Generation)分层
  - 同一代的成员水平排列
  - 子女居中于父亲下方
  - 配偶显示在成员旁边（用双线连接）
- 计算每个节点的 (X, Y) 坐标
- 递归计算子树宽度，避免节点重叠
- 输出：节点坐标字典 + 连线坐标列表

### 3. 排版预览与打印模块 (PrintPreviewWindow)
- Canvas 画布按 A3 尺寸 (297mm x 420mm, 约 1122 x 1684 像素 @96dpi) 渲染
- 顶部显示族谱标题
- 中间渲染树形图（节点 + 连线）
- 每个节点卡片：照片（可选）+ 姓名 + 生卒年 + 配偶（可选）
- 支持缩放预览、拖动平移
- 打印按钮调用系统 PrintDialog
- 支持导出为 XPS/PDF（通过 XpsDocumentWriter）

### 4. 排版设置面板
- 在预览窗口右侧提供设置面板
- 实时调节：节点大小、间距、字体、显示/隐藏字段
- 调节后实时刷新预览
- 支持选择纸张大小和横纵向

## 关键设计决策

1. **布局算法**: 采用改进的 Reingold-Tilford 树布局算法，确保同代节点对齐、子树不重叠
2. **连线样式**: 使用正交折线（水平-垂直-水平），符合传统族谱风格
3. **打印方案**: 使用 FixedPage + XpsDocumentWriter，精确控制 A3 纸张输出
4. **照片处理**: 统一裁剪为圆形或圆角矩形，节省空间
5. **数据库**: SQLite 文件存储在用户文档目录下 `ZupuPaiBan/zupu.db`
